# ТЗ-2

В рамках проекта был разработан и сгенерирован файл, содержащий важные данные: дата продажи, название товара, количество реализованных единиц и цена за единицу. На основе этих данных был создан скрипт, который позволяет определить топ-3 товара по общей сумме продаж, обеспечивая быстрый анализ наиболее прибыльных позиций. Для более наглядного представления результатов был построен график, отображающий разбивку продаж по месяцам, что позволяет отслеживать динамику и сезонные тенденции в продажах товаров.
